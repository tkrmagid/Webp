## 0909 수업내용

1. HTML5 문서의 기본 구조

* `<!DOCTYPE html>`: 이 문서가 HTML5 문서라는 것을 알려주는 선언
* `<html>` 태그 안에 `<head>`와 `<body>`가 들어감
* `<head>`: 문서 제목, 메타데이터, CSS, 자바스크립트 코드가 들어가는 곳
* `<body>`: 실제 화면에 보이는 내용(텍스트, 이미지, 표 등)이 들어가는 곳
* `<!-- -->` 는 주석문. 브라우저 화면에 출력되지 않음

2. HTML 태그의 특징

* 태그는 태그이름과 여러 개의 속성(attribute)으로 구성됨. 속성은 속성이름="속성값" 형태로 씀
* 시작태그와 종료태그가 모두 있는 경우도 있고(`<html>` ... `</html>`), 시작 태그만 있는 경우도 있음(`<br>`)
* 태그 이름과 속성 이름은 대소문자를 구분하지 않음
* 속성 값에 불필요한 공백을 넣는 것은 HTML5 표준에 어긋남

3. 제목, 단락, 줄바꿈 관련 태그

* `<title>`: 브라우저 타이틀바에 표시되는 문서 제목
* `<h1>` ~ `<h6>`: 문단 제목을 다는 태그. 숫자가 작을수록 글자가 크고 중요한 제목
* title 속성: 태그에 붙이면 마우스를 올렸을 때 툴팁이 뜸
* `<p>`: 단락을 나누는 태그. 여러 개의 빈 칸이나 엔터 키는 하나로 처리됨
* `<hr>`: 수평선을 그어주는 태그. 종료 태그 없이 사용
* `<br>`: 강제로 다음 줄로 넘어가게 하는 태그

4. 특수 문자, 기호 표현

* HTML5는 유니코드 문자셋, UTF-8 코드 체계를 사용함
* 키보드로 입력하기 어려운 기호나 예약된 문자(<, > 등)는 엔터티(&엔터티;)나 코드값(&#코드값;)으로 표현
* 예: < 는 &lt;, 공백은 &nbsp;, 저작권 기호는 &copy;

5. `<pre>` 태그

* 사용자가 입력한 형태(줄바꿈, 빈 칸 포함) 그대로 출력하고 싶을 때 사용
* `<p>` 태그는 여러 빈 칸이나 줄바꿈을 하나로 처리하지만, `<pre>`는 입력한 그대로 유지함

6. 텍스트 꾸미기 태그

* `<b>`: 진하게, `<strong>`: 중요한 내용 강조(진하게)
* `<em>`: 강조(이탤릭체), `<i>`: 이탤릭체
* `<small>`: 한 단계 작은 글자
* `<del>`: 취소선(삭제된 내용), `<ins>`: 밑줄(추가된 내용)
* `<sup>`: 윗첨자, `<sub>`: 아래첨자
* `<mark>`: 형광펜처럼 하이라이트 표시

7. 블록 태그와 인라인 태그

* 블록 태그: 항상 새 줄에서 시작하고 한 줄을 독점해서 사용함. 예: `<p>`, `<h1>`, `<div>`, `<ul>`
* 인라인 태그: 블록 속에 삽입되어 블록의 일부로 출력됨. 예: `<strong>`, `<a>`, `<img>`, `<span>`
* 가장 많이 쓰는 블록 태그는 `<div>`, 가장 많이 쓰는 인라인 태그는 `<span>`

8. 메타데이터 삽입

* 메타데이터는 데이터를 설명하는 데이터(예: 사진 찍은 장소, 이미지 폭과 높이 등)
* `<base>`: 웹 페이지의 기본 URL을 지정. 이후 링크에서는 상대경로만 써도 됨
* `<link>`: CSS 같은 외부 자원 파일을 연결할 때 사용
* `<meta>`: 저작자, 문자 인코딩, 설명, 검색 키워드 등 다양한 정보 표현. charset 속성으로 문자 코드 지정

9. 이미지 삽입

* `<img>` 태그의 src 속성에 이미지 파일 주소를 지정
* 지원하는 이미지 종류: BMP, GIF, PNG, JPG(JPEG), animated-GIF
* src(필수): 이미지 파일의 URL
* alt(필수): 이미지를 출력할 수 없을 때 대신 나오는 문자열
* width, height: 이미지 크기 지정. 생략하면 원본 크기로 출력

10. 리스트 만들기

* 순서 있는 리스트: `<ol>` ... `</ol>`. type 속성으로 마커 모양(1, A, a, I, i) 지정, start 속성으로 시작 번호 지정
* 순서 없는 리스트: `<ul>` ... `</ul>`
* 정의 리스트: `<dl>` ... `</dl>`. `<dt>`는 용어, `<dd>`는 그 용어에 대한 설명
* 리스트 아이템은 `<li>`로 표시하며, 종료 태그 `</li>`는 생략 가능
* 리스트 안에 또 다른 리스트를 넣는 중첩 리스트도 가능

11. 표 만들기

* `<table>`: 표 전체를 담는 컨테이너
* `<caption>`: 표 제목. table 안에서 반드시 첫 번째로 와야 함
* `<thead>`: 헤딩(제목) 셀 그룹, `<tbody>`: 실제 데이터 셀 그룹, `<tfoot>`: 바닥 셀 그룹
* `<tr>`: 표의 한 행. 여러 개의 `<th>`나 `<td>`를 포함
* `<th>`: 제목(헤딩) 셀, `<td>`: 데이터 셀
* 표 안에 이미지도 삽입할 수 있음

12. 하이퍼링크 만들기

* `<a>` 태그의 href 속성으로 다른 웹 페이지를 연결
* 텍스트뿐 아니라 이미지도 하이퍼링크로 만들 수 있음
* 하이퍼링크 텍스트 색: 처음에는 파란색과 밑줄, 방문한 링크는 보라색, 클릭하는 순간은 빨간색
* target 속성으로 링크를 열 위치 지정: _blank(새 창), _self(현재 창), _parent(부모 윈도우), _top(최상위 브라우저 윈도우), 혹은 프레임 이름
* id 속성으로 페이지 안에 특정 위치(앵커)를 만들고, href="#앵커이름"으로 그 위치로 바로 이동하는 링크를 만들 수 있음
* download 속성을 붙이면 링크를 클릭했을 때 파일이 다운로드됨

13. 인라인 프레임

* `<iframe>` 태그로 하나의 HTML 페이지 안에 다른 HTML 페이지를 삽입할 수 있음
* src 속성에는 출력할 페이지 주소, srcdoc 속성에는 직접 작성한 HTML 텍스트를 넣을 수 있음(둘 다 있으면 srcdoc이 우선)
* width, height로 프레임 크기 지정, name으로 프레임 창의 이름 지정
* 브라우저 창과 프레임 창은 부모-자식 관계를 가짐. parent(부모 윈도우), child(자식 윈도우), top(최상위 브라우저 윈도우)라는 용어를 사용
* target 속성을 활용하면 링크를 클릭했을 때 특정 프레임에 페이지를 출력할 수 있음

14. 오디오, 비디오 삽입

* HTML5부터는 플러그인 없이 `<video>`, `<audio>` 태그만으로 미디어를 재생할 수 있음
* `<video>`: src 속성에 파일 주소, width/height로 크기, controls로 제어 버튼 표시, autoplay로 자동 재생, loop로 반복 재생, muted로 음소거
* `<audio>`도 마찬가지로 controls, autoplay, loop 속성을 사용할 수 있음
* `<source>` 태그로 여러 형식의 파일을 순서대로 지정해서, 브라우저가 지원하는 형식을 골라 재생하게 할 수 있음
* 최신 브라우저는 보안 때문에 autoplay가 잘 작동하지 않고, 사용자가 직접 재생 버튼을 눌러야 재생됨
