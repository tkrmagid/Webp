## 0902 수업내용

1. 웹의 기본 개념

* 웹(Web): 여러 컴퓨터에 있는 문서와 정보를 서로 공유하고 볼 수 있도록 만든 서비스
* WWW(World Wide Web): 인터넷을 이용해 정보들이 거미줄처럼 연결된 구조

구성 요소
* 웹 서버: 웹사이트의 HTML, 이미지, 동영상 등의 자료를 저장하고 요청에 응답하는 컴퓨터. 예: 구글, 네이버
* 웹 클라이언트: 사용자가 브라우저를 통해 웹 문서를 요청하고 화면에 보는 역할

동작 순서: 클라이언트가 문서를 요청하면 서버가 문서를 전송해줌

2. 인터넷과 웹의 차이

* 인터넷: 여러 컴퓨터를 연결하는 네트워크이며 IP 주소로 컴퓨터를 구분함 (1969년 미국방성 ARPA에서 시작)
* 인터넷을 이용하는 서비스들: 이메일, 뉴스, ftp, 채팅, 메신저, P2P, 스트리밍, 인터넷전화 그리고 웹
* 웹: 인터넷을 기반으로 정보를 제공하는 서비스 중 하나
* 쉽게 말하면 인터넷은 고속도로, 웹은 그 고속도로를 이용하는 서비스라고 볼 수 있음

3. 웹 브라우저

* 종류: 크롬, 파이어폭스, 엣지, 오페라, 사파리 등
* 역사: 1990년 WorldWideWeb(팀 버너스리가 개발한 최초의 브라우저) → 넷스케이프 내비게이터(1994) → 인터넷 익스플로러(1995) → 오페라(1996) → 파이어폭스(2002) → 사파리(2003) → 크롬(2008) → 엣지(2015)
* 2021년 기준 점유율은 데스크톱, 모바일 모두 크롬이 압도적 1위

4. 웹 사이트 구축과 웹 서버 소프트웨어

* 웹사이트를 만들려면: 웹서버 소프트웨어 설치 → 문서/이미지/동영상 저장 및 데이터베이스 설치 → 서버 응용프로그램 개발
* 웹서버 소프트웨어: 브라우저의 요청을 해석하고 필요한 프로그램을 실행시킨 뒤 결과를 전송함. 종류로는 아파치, IIS, nginx, GWS가 있음
* 웹서버 응용프로그램: 검색, 로그인, 회원관리, 주문 등 사이트 실제 기능을 수행하는 프로그램. JSP, 자바 서블릿, PHP, 파이썬 등으로 개발

5. 웹 문서와 전자 문서

웹 문서
* 페이지 단위로 나누어 저장
* 하이퍼링크로 서로 연결
* 사용자가 원하는 순서대로 이동 가능

전자 문서
* 하나의 파일에 내용을 저장
* 작성자가 정한 순서대로 읽음

6. URL의 구조

예시: http://www.oracle.com:80/technetwork/java/index.html
http: 프로토콜
www.oracle.com: 서버 주소
80: 포트 번호
/technetwork/java: 경로
index.html: 파일 이름

7. HTTP 통신 과정

브라우저가 서버에 연결을 요청하면 서버가 연결을 수락하고, 브라우저가 문서를 요청하면 서버가 그 문서를 읽어서 전송해준다. 마지막으로 브라우저가 받은 문서를 해독해서 화면에 출력한다. 이 과정을 HTTP 세션이라고 부름

8. 웹을 선호하는 이유

* HTML 태그를 배우기 쉬움
* HTTP 통신으로 효율적인 서비스 제공 (문서 전송 후 연결을 끊어서 서버 부담이 적음)
* 서버와 클라이언트가 작업을 나누어 처리 가능 (서버는 자원 전송만, 화면 출력은 브라우저 담당)
* 웹은 TV, 셋톱박스, 공유기 같은 다양한 기기에도 쓰일 수 있음

9. 웹 페이지의 3요소

* HTML: 웹페이지의 구조와 내용
* CSS: 디자인과 화면 꾸미기
* JavaScript: 사용자와의 상호작용
* HTML = 뼈대 / CSS = 디자인 / JavaScript = 움직임과 기능
* 예제로 배운 내용: 처음엔 HTML만으로 뼈대만 있는 페이지를 만들고, style 태그로 CSS를 추가해서 색과 배치를 꾸미고, script 태그로 자바스크립트를 추가해서 마우스를 올리면 이미지가 나타나는 기능까지 구현해봄
