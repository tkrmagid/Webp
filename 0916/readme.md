# 0916 수업내용

1. HTML5 문서 구조화가 필요한 이유

* 기존 HTML의 한계: `<div>`나 `<table>`로 구조화된 것처럼 보이게만 작성해서, 소스만 봐서는 문서 구조를 파악할 수 없음
* 구조화가 필요한 이유: 검색엔진이 좋아하는 페이지를 만들기 위해, 사물인터넷 장치들이 스스로 정보를 검색하는 시대라서
* 시맨틱 웹: 문서를 구조화해서 의미 있는 내용 탐색이 쉬운 웹
* 시맨틱 태그: 문서의 구조와 의미를 전달하는 태그. `<header>`, `<section>`, `<article>`, `<main>`, `<summary>`, `<mark>`, `<time>` 등

2. 주요 시맨틱 블록 태그

* `<header>`: 페이지나 섹션의 머리말. 제목이나 간단한 소개
* `<nav>`: 하이퍼링크들을 모아놓은 영역. 목차 만드는 용도
* `<section>`: 문서의 장이나 절을 구성. 여러 개 사용 가능하고 헤딩 태그(`<h1>`~`<h6>`)로 주제 표시
* `<article>`: 본문과 연관 있지만 독립적인 콘텐츠(블로그 포스트, 댓글 등). 여러 `<section>`을 포함할 수도 있음
* `<aside>`: 본문에서 약간 벗어난 노트나 팁. 페이지 옆쪽에 주로 배치
* `<footer>`: 꼬리말 영역. 저자나 저작권 정보
* 시맨틱 태그는 위치나 색, 모양이 자동으로 정해지지 않고, CSS3로 개발자가 직접 꾸며야 함

3. 문서 구조화할 때 권장 사항

* 웹 페이지 전체를 시맨틱 태그로 분할
* 제목과 소개는 `<header>`로 작성
* 본문은 `<section>`으로 묶고, 본문 안의 각 절은 `<article>`로 작성
* 링크나 메뉴는 `<nav>` 태그로 작성
* 각 영역에는 헤딩 태그(`<h1>`~`<h6>`)로 제목을 붙임
* 배경음악 재생하는 `<audio>`는 `<header>` 영역에 삽입
* 전체적인 배치와 모양은 CSS3 스타일 시트로 꾸밈

4. 그 밖의 시맨틱 태그

* `<figure>`, `<figcaption>`: 사진, 차트, 삽화, 소스코드 등을 '그림'으로 블록화해서 표현
* `<details>`, `<summary>`: 상세 정보를 접었다 펼쳤다 할 수 있는 태그. `<summary>`가 제목 역할, 클릭(핸들 ▶)하면 상세 내용이 펼쳐짐
* 시맨틱 인라인 태그
  * `<mark>`: 중요한 텍스트 표시(하이라이트)
  * `<time>`: 텍스트 내용이 시간임을 표시
  * `<meter>`: 범위나 퍼센트 데이터량 표시
  * `<progress>`: 작업 진행 정도 표시

5. HTML5에서 제거된 태그

* 문서의 시맨틱 구조를 저해한다는 이유로 제거됨. `<big>`, `<center>`, `<dir>`, `<font>`, `<tt>`, `<u>`, `<xmp>`, `<acronym>`, `<applet>`, `<basefont>`, `<frame>`, `<frameset>`, `<noframes>`, `<strike>` 등

6. 웹폼의 기본 구조

* 웹폼: 로그인, 등록, 검색, 예약, 쇼핑 등 웹 페이지에서 사용자 입력을 받는 폼
* 폼 요소: `<input>`, `<textarea>`, `<select>` 등 다양한 태그로 구성
* `<form>` 태그로 폼 요소들을 감쌈
  * name 속성: 폼의 이름 지정
  * action 속성: 폼 데이터를 처리할 웹 서버 응용프로그램 지정. submit 버튼을 누르면 이 프로그램의 실행을 요청함
  * method 속성: 폼 데이터를 서버로 전송하는 방식(GET, POST가 대표적)
* 네이버 검색으로 예를 들면: 검색어를 입력하고 버튼을 누르면 브라우저가 action에 지정된 주소로 데이터를 붙여서 요청을 보내고, 서버가 처리한 결과를 다시 브라우저에 돌려줘서 화면에 출력됨

7. 텍스트 입력 관련 요소

* `<input type="text">`: 한 줄짜리 입력창
* `<input type="password">`: 암호 입력창. 입력한 문자 대신 '*' 등으로 표시됨
* `<textarea>`: 여러 줄 입력창
* `<datalist>`: 입력 가능한 데이터 목록(드롭다운)을 제공. `<option>` 태그로 각 항목을 표현하고, input의 list 속성으로 연결

8. 버튼 만들기

* `<input type="button|reset|submit|image">`로 버튼을 만들 수 있음
* `<button type="button|reset|submit">버튼 문자열</button>`로도 버튼을 만들 수 있음(안에 이미지도 넣을 수 있어 더 자유로움)

9. 선택형 입력 요소

* `<input type="checkbox">`: 체크박스. checked 속성을 넣으면 처음부터 체크된 상태로 출력
* `<input type="radio">`: 라디오버튼. name 속성 값이 같은 것끼리 하나의 그룹이 되어 그중 하나만 선택 가능
* `<select>` + `<option>`: 콤보박스(드롭다운 목록). option에 selected 속성을 넣으면 처음부터 선택된 상태로 출력

10. `<label>` 태그로 캡션 달기

* 폼 요소와 캡션(설명 텍스트)을 한 단위로 묶어주는 태그
* 방법 1: `<label>캡션 텍스트 <input ...></label>` 처럼 통째로 감싸기
* 방법 2: `<label for="아이디">캡션</label>` 과 `<input id="아이디">` 로 서로 연결하기
* 체크박스나 라디오버튼에 label을 쓰면 캡션 글자를 클릭해도 선택이 됨

11. 색 표현과 색 입력

* 색 코드는 #rrggbb 형태. rr(빨강), gg(초록), bb(파랑) 각각 0~255를 16진수(00~FF)로 표기
* `<input type="color">`: 컬러 다이얼로그를 열어서 사용자가 색을 직접 선택할 수 있음. value 속성으로 초기 색 지정

12. 시간 정보 입력 요소

* `<input type="month|week|date|time|datetime-local">`
* 각각 달, 주, 날짜, 시간, 날짜+시간을 입력받는 용도이며 버튼을 눌러 달력이나 시간 선택 UI가 뜸

13. 숫자 입력 요소

* `<input type="number">`: 스핀버튼으로 정교한 숫자 값 입력. min, max, step 속성으로 범위와 증감 단위 지정
* `<input type="range">`: 슬라이드바로 대략적인 값 입력. datalist를 연결하면 중간중간 눈금을 표시할 수 있음

14. 힌트와 형식을 가진 텍스트 입력

* placeholder 속성: 입력창에 무엇을 입력해야 하는지 힌트 텍스트를 보여줌(회색 글씨)
* `<input type="email">`: 이메일 주소 형식 입력. 형식이 틀리면 제출할 때 오류 표시
* `<input type="url">`: URL 입력
* `<input type="tel">`: 전화번호 입력
* `<input type="search">`: 검색어 입력

15. 폼 요소 그룹핑

* `<fieldset>`: 관련 있는 폼 요소들을 하나의 그룹 박스로 묶어주는 태그
* `<legend>`: fieldset 그룹의 제목을 붙이는 태그
